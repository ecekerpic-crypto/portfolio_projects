# PDF Birleştirici

Bu proje, iki PDF dosyasını tek bir PDF dosyası haline getiren basit bir Python uygulamasıdır.

## Özellikler

- PDF dosyalarını birleştirir
- Yeni bir çıktı PDF dosyası oluşturur
- PyPDF2 kütüphanesini kullanır
- Dosya yollarını otomatik olarak proje klasöründen alır

## Kullanılan Teknolojiler

- Python
- PyPDF2
- os modülü

## Nasıl Çalışır?

1. `dosya1.pdf` ve `dosya2.pdf` proje klasörüne eklenir.
2. Program çalıştırılır.
3. `birlesmis_dosya.pdf` adlı yeni PDF oluşturulur.
