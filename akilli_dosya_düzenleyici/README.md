# Akıllı Dosya Düzenleyici

Bu Python projesi, klasörde bulunan dosyaları otomatik olarak türlerine göre ayırır.

## Özellikler
- Resimleri ayırır
- Videoları ayırır
- Belgeleri ayırır
- Otomatik klasör oluşturur

## Kullanılan Teknolojiler
- Python
- os modülü
- shutil modülü

## Nasıl Çalışır?
Program çalıştırıldığında dosyaları otomatik olarak ilgili klasörlere taşır.
