# Todo App

Bu proje, görev ekleme ve silme işlemleri yapabilen basit bir yapılacaklar listesi uygulamasıdır.

## Özellikler

- Görev ekleme
- Görev silme
- Basit pencere arayüzü
- Tkinter kullanılarak oluşturulmuş kullanıcı arayüzü

## Kullanılan Teknolojiler

- Python
- Tkinter

## Nasıl Çalışır?

1. Kullanıcı görev yazar.
2. "Görev Ekle" butonuna basar.
3. Görev listeye eklenir.
4. Seçilen görev silinebilir.

## Çalıştırma

```bash
python main.py
